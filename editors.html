محررات أونلاينجرّب أفكارك مباشرة من المتصفح دون أي تثبيت

  • Google Colabدفاتر بايثون (Notebooks) تشتغل من المتصفح بدون تثبيت، مناسبة لتحليل البيانات والذكاء الاصطناعي، ومجانية بحساب Googlecolab.research.google.com
  • OnlineGDBتشغيل وتصحيح أكواد C وC++ وJava وPython من المتصفح بدون تثبيتonlinegdb.com
  • StackBlitzبيئة تطوير كاملة في المتصفح، مناسبة لمشاريع الفرونت إند والمكتبات الحديثة مثل React وVuestackblitz.com
  • Replitتجربة وتشغيل أي لغة برمجة من المتصفح، مناسبة للتجربة السريعة (الخطة المجانية محدودة)replit.com

محررات وبيئات تطوير لويندوزخيارات موثوقة ومعتمدة عالميًا

  • Visual Studio Codeمحرر خفيف ومجاني بإضافات كثيرة، الأشهر بين الطلبةcode.visualstudio.com
  • Notepad++محرر نصوص وأكواد سريع وخفيف لويندوزnotepad-plus-plus.org
  • Code::Blocksبيئة مجانية مفتوحة المصدر لـ C وC++ سهلة للمبتدئين — حمّل نسخة MinGW عشان المترجم يجي معاهاcodeblocks.org
  • PyCharmبيئة JetBrains المتكاملة لتعلم Pythonjetbrains.com
  • IntelliJ IDEAبيئة JetBrains المتكاملة لـ Java وKotlin، وأساسياتها مجانيةjetbrains.com
  • Visual Studioبيئة مايكروسوفت المتكاملة لـ C# وC++ وتطبيقات ويندوزvisualstudio.microsoft.com
  • Android Studioالبيئة الرسمية لتطوير تطبيقات أندرويد من Googledeveloper.android.com

محررات لأندرويدللكتابة والتجربة من الهاتف أو التابلت

  • Acodeمحرر أكواد مفتوح المصدر لأندرويد، مناسب للويب مع معاينة فوريةplay.google.com
  • Spck Editorمحرر لمشاريع الويب مع دعم Git ومعاينة مباشرةplay.google.com
  • Pydroid 3بيئة Python تعمل على الهاتف بدون إنترنتplay.google.com
  • Termuxطرفية لينكس كاملة على الهاتف — يُنصح بتثبيتها من F-Droid أو GitHub وليس من Google Playtermux.dev

محررات للآيفونللتعديل السريع والتعلّم من الهاتف أو الآيباد

  • Textasticمحرر أكواد متكامل للآيفون والآيباد، يدعم أكثر من 80 لغة وSFTPapps.apple.com
  • Spck Editorمحرر لمشاريع الويب مع دعم Git ومعاينة مباشرةapps.apple.com
  • Pythonista 3بيئة Python كاملة على iOS لتشغيل السكربتات وبناء واجهات صغيرةapps.apple.com
