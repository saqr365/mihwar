# محور (Mihwar)

دليل رقمي بالعربي (RTL) لطلبة الجامعات: أدوات، إضافات متصفح، محررات أكواد، وخوادم DNS.

موقع ثابت (HTML / CSS / JavaScript) بدون أي frameworks.

## الصفحات
- `index.html` — الصفحة الرئيسية
- `learn.html` — التعلم
- `editors.html` — محررات الأكواد
- `extensions.html` — إضافات المتصفح
- `specs.html` — المواصفات
